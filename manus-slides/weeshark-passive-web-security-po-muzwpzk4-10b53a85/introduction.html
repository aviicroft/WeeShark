Introduction | Making Posture Visible

Framing the necessity of low-impact, passive security auditing.

Modern web security requires continuous assessment of the visible surface area. While invasive penetration testing is critical, it often lacks the lightweight repeatability needed for baseline posture monitoring.

WeeShark bridges this gap by providing a deterministic, non-destructive audit engine that evaluates the defensive configuration of public-facing assets without service interruption.

Core Assessment Vectors

Transport Hygiene Evaluating TLS handshake validity and protocol version compliance.
Defensive Response Headers Validating CSP, HSTS, XFO, and XCTO configurations.
Privacy Controls Inspecting cookie attributes (Secure, HttpOnly, SameSite).
Exposure Management Detecting service banners and unauthorized port accessibility.
