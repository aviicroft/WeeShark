Why Unnecessary Information Disclosure Matters

In the reconnaissance phase of an attack, adversaries scan web headers to fingerprint the exact operating system, web server daemon (e.g. Apache/2.4.41, nginx/1.18.0), and application framework (e.g. Express, PHP/7.4.3, ASP.NET).

Exposing exact software version numbers enables attackers to search the National Vulnerability Database (NVD) for unpatched Common Vulnerabilities and Exposures (CVEs) specific to that build. Hiding or generalizing these banners deprives attackers of immediate intelligence and forces them to work blind.

Nginx Hardening

Suppress server version tokens in nginx.conf:

http {
    server_tokens off;
}

Apache Hardening

Suppress banners in httpd.conf or security.conf:

ServerTokens Prod
ServerSignature Off

Express.js Hardening

Disable X-Powered-By in Node.js Express:

app.disable('x-powered-by');
// or use helmet()
